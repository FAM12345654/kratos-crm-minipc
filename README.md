# Kratos CRM — Familienhelden

Privates Repository für den Kratos-Quellcode und die Einrichtung auf dem Windows-Mini-PC.

- [Quellcode-Paket herunterladen](kratos-crm-minipc-source.zip)
- [Mini-PC-Anleitung: Downloads, lokaler Start und Serverstatus](docs/mini-pc-server-setup.md)

## Status

Der aktuelle Quellcode ist die veröffentlichte Sites-Webanwendung mit Cloudflare D1. Er ist noch kein produktionsfertiger Windows-CRM-Server. Für einen sicheren Mini-PC-Server müssen unter anderem der SQLite-Adapter, geschützte OAuth-Anmeldung, Graph-Token-Erneuerung, Dienstbetrieb sowie Backup und Wiederherstellung umgesetzt und geprüft werden.

Die lokale Vorschau ist ausschließlich für synthetische Testdaten vorgesehen. Keine echten Kundendaten oder Geheimnisse in dieses Repository laden.
